# Contribuindo

Obrigado por contribuir com o CloseAppsOpen.

## Antes de começar

- Use Windows e o .NET 10 SDK para compilar e testar o projeto.
- Consulte as issues existentes antes de abrir uma nova. Para mudanças maiores, descreva a proposta em uma issue antes de implementar.
- Não inclua dados pessoais, credenciais, binários de build ou arquivos gerados no pull request.

## Enviando uma alteração

1. Crie uma branch a partir de `master`.
2. Faça uma alteração focada e inclua testes quando modificar comportamento.
3. Execute `dotnet test CloseAppsOpen.slnx -c Release`.
4. Abra um pull request explicando o problema, a solução e como validou a mudança.

O projeto usa a licença MIT. Ao enviar uma contribuição, você concorda que ela seja distribuída sob essa licença.
